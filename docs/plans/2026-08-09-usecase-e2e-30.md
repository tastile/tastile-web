## Context

`tastile-core` (Rust backend, v1 era) completed a 30 USECASE + §25.x
mapping reverification on 2026-08-09 with 776 passed / 0 failed across
86 suites (`tastile-core/evidence/2026-08-09-core-usecase-reverification.md`).
That mapping is **API-direct**: it drives the Rust HTTP handlers via
curl + psql, not through the Next.js thin client.  The remaining gap is
to pin the same 30 contracts through `tastile-web`'s proxy and UI
surfaces, so that "the user can actually open the dashboard and see this
happen" is end-to-end verified.

Per memory `feedback_no_unverified_pass.md`, "PASS without execution"
is treated as a serious breach of trust.  Every spec in this plan must
produce a real execution trace (Playwright run, optional chrome-devtools
MCP snapshot) and have the trace attached to the spec's evidence file.

## Stack boot procedure (`scripts/e2e/up-stack.sh`)

1. `wslc container ls | grep tastile-dev-api` — running 確認 (無ければ `bash scripts/wslc/up-v1.sh`)
2. `wslc container exec tastile-db pg_isready -U tastile` — PostgreSQL ready
3. `wslc container exec tastile-dev-api curl -s http://127.0.0.1:31400/v1/ready` — HTTP 200 wait (timeout 30s, `pollUntil`)
4. `wslc container exec tastile-db psql -U tastile -d tastile_db -tA -c "SELECT max(version) FROM v1_migration"` — V1_022 以降を確認
5. `bun run dev > docs/plans/evidence/2026-08-09-usecase-e2e-30/dev-server.log 2>&1 &` — Next.js dev server 起動
6. `curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3000/dashboard` — 2xx or auth redirect
7. 上記を `boot.md` に dump

## Per-spec procedure (`scripts/e2e/run-spec.sh <NN>`)

1. `bun run test:e2e -- e2e/usecase-NN-*.spec.ts --reporter=json > docs/plans/evidence/2026-08-09-usecase-e2e-30/<NN>-<slug>.json`
2. pass/fail を parse して `<NN>-<slug>.md` に貼る
3. UI spec は chrome-devtools MCP `take_snapshot` を同じ md に貼る
4. API-only spec は psql ground truth (`SELECT count(*) FROM v1_*`) を同じ md に貼る

## Teardown (`scripts/e2e/down-stack.sh`)

1. dev server PID kill
2. wslc container は起動維持 (次回 run で再利用)

## Risks and mitigations

| Risk | Mitigation | Rollback |
|---|---|---|
| Single PR 6000+ lines | Helpers 5 ファイル分散 + spec 1 件 100-150 行目安 | 必要なら 5 PR に分割 |
| Helper 追加で既存 40 件に regression | `resetDb` 拡張は idempotent、新規 helper は pure additive | helper 削除 + git revert |
| UI spec が chrome-devtools MCP 観測欠落 | spec テンプレ step 3 必須化 | VERIFIED 判定を出さず PR 保留 |
| USECASE 19/20 timing flake | `pollUntil` (timeoutMs 30000) で worker tick 待機 | evidence SUMMARY に deferred フラグ |
| API-only spec が存在しない surface を assert | Phase 1 readiness: `crates-v1/api/src/handlers/` grep で handler 在確認 | KNOWN-GAP マークで PR block しない |
| 単一 PR CI runtime 膨張 | 既存 ~3min + 30 specs × ~10s = +5min → 合計 ~8min 許容 | `test:e2e:usecase` 新設、PR check は 19 件代表のみ、nightly で full 30 件 |
